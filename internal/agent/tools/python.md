# Python

Use this tool when exact computation or verification is required.

## When To Use

1. Math, statistics, probabilities, finance, and unit conversion
2. Structured data processing over JSON, CSV, logs, or tabular input
3. Verification when correctness depends on actual execution
4. Large or repetitive transformations where Python is the reliable option
5. Any case where a wrong answer would cause downstream failure

## When Not To Use

1. Simple factual recall
2. Summarization, drafting, translation, or explanation
3. Planning or general reasoning
4. Subjective judgment or recommendations
5. Simple tasks where execution does not improve correctness

## Input

- Provide a concise task prompt describing what must be computed, verified, or transformed.
- State the expected result clearly.
- Include the data needed for the computation in the prompt.

## Output

- The tool executes through Gemini code execution.
- It returns the execution-backed answer and execution metadata.
